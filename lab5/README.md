# ЛР5. Закон Ципфа

Требования: Python 3.8+ (только стандартная библиотека), токенизатор из ЛР3 (`../lab3`, собирается `make`: `g++` с C++17, glibc 2.35+), `pdflatex` с пакетом `pgfplots` для отчёта. Корпус — тексты из ЛР1, по умолчанию корпус на 1 млн документов (`../lab1/data_1m/text`).

Запуск всего с нуля: `./run.sh [каталог_корпуса]` — сборка токенизатора, автотесты, подсчёт частот, отчёт (на корпусе 1 млн документов `../lab1/data_1m/text` — около 5 минут).

- `scripts/zipf.py <корпус> <каталог>` — частоты терминов всех `*.txt` корпуса: `freq.tsv` (ранг, термин, частота), `zipf.dat` (точки графика и закон Ципфа C/r, C = f(1)), `summary.tsv`, `ranks-table.tex`.
- `tests/run_tests.py` — автотесты (`results/tests.log`).
- `report/` — отчёт (LaTeX, график — `pgfplots` из `results/zipf.dat`), `report/report.pdf`.
