# ЛР11. Сжатие

Требования: Linux с glibc 2.35+, `g++` с C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Используются токенизатор ЛР3, стеммер ЛР4, индексатор и читатель индекса ЛР7, поиск ЛР8 и корпус ЛР1 на 1 млн документов (`../lab1/data_1m`, список документов `../lab7/data/docs.tsv`, индекс без сжатия `../lab7/data/index.bin`).

Запуск всего с нуля: `./run.sh` — сборка, автотесты, индексация корпуса без сжатия и со сжатием по 2 раза (10–20 минут), замеры и сверка, отчёт.

- `src/vbyte.h` — кодек Variable Byte: разности соседних docID, 7 бит на байт, бит 7 = 1 у последнего байта числа. Подключается в индексатор и читатель индекса ЛР7 (а через него — в поиск ЛР8).
- `../lab7/build/indexer -c INDEX < docs.tsv` — индекс со сжатыми списками документов (в заголовке флаг 2; с `-s` — флаги 3). `../lab8/build/search INDEX` и `../lab7/build/lookup INDEX` читают оба вида индекса сами, по флагу.
- `build/listbench INDEX [-r REPEAT]` — размер и время прохода по спискам документов по группам термов: все, редкие (df ≤ 100), средние (100 < df ≤ 10 000), частые (df > 10 000) и по десятичным диапазонам df.
- `build/listbench -v INDEX_A INDEX_B` — сверка двух индексов: термы, df, все списки и записи документов.
- `scripts/indexing.py` — индексация корпуса без сжатия и со сжатием (по 2 раза, порядок чередуется), время по этапам и размеры (`results/indexing.tsv`); строит `data/index-vb.bin` (615 МиБ).
- `scripts/bench.py` — проход по спискам (`results/lists.tsv`), время запросов ЛР8 по обоим индексам (`results/search.tsv`, `bench-summary.tsv`), сверка индексов и полной выдачи поиска (`results/verify.txt`), таблицы для отчёта.
- `tests/test_compress.cpp` — юнит-тесты на C++: `make test`, журнал — `results/tests.log`.
- `report/` — отчёт (LaTeX), `report/report.pdf`.
