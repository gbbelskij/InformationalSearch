\CWHeader{Лабораторная работа \textnumero 11 \enquote{Сжатие}}

В этом задании необходимо применить алгоритмы сжатия к координатным блокам. Исследовать изменения в размерах частей индекса, влияние на скорость индексации и поиска.

В отчёте нужно указать:
\begin{itemize}
    \item Выбранный метод сжатия. Привести побитовую схему хранения данных в индексе. Описать причины, по которым был выбран именно этот метод сжатия.
    \item Влияние сжатия на размер и скорость прохождения по координатным блокам всех терминов, редких терминов, терминов средней частотности и высокочастотных терминов.
    \item Обосновать, почему поиск после внедрения сжатия работает корректно. Как производилось тестирование?
\end{itemize}
