# ЛР13. Ранжирование TF-IDF

Требования: Linux с glibc 2.35+, `g++` с C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Используются токенизатор ЛР3, стеммер ЛР4, индексатор и читатель индекса ЛР7, поиск и веб-сервис ЛР8, кодек VByte ЛР11 и корпус ЛР1 на 1 млн документов (список документов `../lab7/data/docs.tsv`).

Запуск всего с нуля: `./run.sh` — сборка, автотесты, индекс с частотами (если его ещё нет, около 3 минут), оценка качества по готовой разметке, замеры, отчёт.

- `src/rank.h` — ранжирование lnc.ltc: веса, нечёткий и булев режимы, накопление оценок по спискам документов, сортировка выдачи слиянием (без STL). Подключается в поиск ЛР8.
- `../lab7/build/indexer -t [-c] INDEX < docs.tsv` — индекс с частотами термов в документах и длинами векторов документов (флаг 4 в заголовке; с `-c` списки сжаты VByte — флаги 6).
- `../lab8/build/search INDEX` — если у индекса флаг 4, выдача ранжируется по TF-IDF: запрос из слов без операторов — нечёткий (документы хотя бы с одним словом), с операторами `&& || ! ( )` — булев, порядок по TF-IDF; пятый столбец выдачи — оценка. По индексу без частот — прежний булев поиск ЛР8. Веб-сервис ЛР8 (`python3 ../lab8/web/server.py --index data/index-tf.bin`) показывает оценку под каждым результатом.
- `data/index-tf.bin` — индекс корпуса с частотами (966 МиБ).
- `data/queries.tsv` — 12 запросов с информационной потребностью; `data/qrels.tsv` — оценки 0/1/2 с обоснованием (разметка вслепую, см. отчёт).
- `scripts/pool.py` — пул для разметки: первые 10 результатов трёх систем (булев по docID, TF-IDF нечёткий, TF-IDF со строгим И), выдержки текста (`results/pool-*.txt`, ключи — `data/pool-key.tsv`).
- `scripts/evaluate.py` — P@10, NDCG@10, ERR@10 по системам (`results/eval.tsv`, `eval-summary.tsv`), выдача с оценками (`results/runs.txt`).
- `scripts/bench.py` — размеры индексов и время запросов (`results/bench.tsv`, `bench-summary.tsv`, `lab8-queries.tsv`).
- `tests/test_rank.cpp` — юнит-тесты на C++: `make test`, журнал — `results/tests.log`.
- `report/` — отчёт (LaTeX), `report/report.pdf`.
