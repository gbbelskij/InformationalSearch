# ЛР3. Токенизация

Требования: Linux с glibc 2.35+ (встроенная локаль `C.UTF-8`), `g++` с поддержкой C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Корпус — тексты из ЛР1, по умолчанию корпус на 1 млн документов (`../lab1/data_1m/text/<источник>/*.txt`, источники находятся сами).

Запуск всего с нуля: `./run.sh [каталог_корпуса]` — сборка, автотесты, замеры, отчёт (на корпусе 1 млн документов `../lab1/data_1m/text` — около 20 минут).

- `src/tokenizer.h` — функция токенизации `tok::tokenize` (подключается к индексатору); `src/stats.h` — подсчёт статистики по файлам; `src/main.cpp` — утилита `build/tokenizer`, сборка `make`.
- `build/tokenizer < text > tokens` — токены текста со стандартного ввода, по одному на строку.
- `build/tokenizer -s < files > stats` — на вход список путей к файлам; статистика: число токенов, средняя длина, время чтения и токенизации, скорость.
- `tests/test_tokenizer.cpp` — юнит-тесты на C++ (каркас `tests/unittest.h`, общий для ЛР3, 4, 7, 8): `make test`, журнал — `results/tests.log`.
- `scripts/bench.py [каталог_корпуса]` — статистика по источникам (`results/stats.tsv`) и время на подвыборках корпуса (`results/bench.tsv`), таблицы для отчёта.
- `report/` — отчёт (LaTeX), `report/report.pdf`.
