# ЛР4. Стемминг

Требования: Linux с glibc 2.35+, `g++` с C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Используются токенизатор ЛР3, индексатор ЛР7, поиск ЛР8, скрипт частотного списка ЛР5 и корпус ЛР1 на 30 тыс. документов (`../lab1/data`, не `data_1m`: оценки релевантности привязаны к его docID). Свои копии: список документов `data/docs.tsv`, индекс без стемминга `data/index.bin`, частотный список `data/zipf/freq.tsv`.

Запуск всего с нуля: `./run.sh` — сборка, автотесты, индекс со стеммингом, статистика, оценка качества, отчёт (около 2 минут).

- `src/porter.h` — стеммер Портера (1980) для английского, без библиотек; подключается в индексатор ЛР7 и поиск ЛР8.
- `build/stem < text` — для каждого токена текста строка `токен<TAB>основа`.
- `../lab7/build/indexer -s INDEX < docs.tsv` — индекс по основам (в заголовке флаг 1); `../lab8/build/search INDEX` сам стеммирует запрос, если у индекса стоит флаг.
- `data/queries.tsv` — 14 запросов с описанием информационной потребности; `data/qrels.tsv` — оценки релевантности (запрос, docID, 0/1, обоснование).
- `scripts/index_stats.py` — индекс `data/index-stem.bin` и сравнение с индексом без стемминга (`results/index-stats.tsv`).
- `scripts/conflation.py` — какие словоформы склеиваются в одну основу (`results/conflation.txt`, по частотному списку ЛР5).
- `scripts/pool.py` — первые 10 результатов обеих систем с фрагментами текста для разметки (`results/pool.txt`).
- `scripts/evaluate.py` — P@10 и число найденных документов без стемминга и со стеммингом (`results/eval.tsv`, `eval-summary.tsv`), разбор изменившейся выдачи (`results/changes.txt`).
- `tests/test_stemmer.cpp` — юнит-тесты на C++ (шаги алгоритма, 77 эталонных слов из `tests/porter_cases.tsv`, индекс и поиск со стеммингом, утилиты): `make test`, журнал — `results/tests.log`.
- `report/` — отчёт (LaTeX), `report/report.pdf`.
