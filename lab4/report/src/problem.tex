\CWHeader{Лабораторная работа \textnumero 4 \enquote{Стемминг}}

Добавить в созданную поисковую систему стемминг (в задании --- \enquote{лемматизация / стемминг}; выполнен вариант со стеммингом). В простейшем случае это просто поиск без учёта словоформ. В более сложном случае можно давать бонус большего размера за точное совпадение слов.

Стемминг можно добавлять на этапе индексации, можно на этапе выполнения поискового запроса.

В отчёте должна быть включена оценка качества поиска после внедрения стемминга. Стало ли лучше? Изучите запросы, где качество ухудшилось. Объясните причину ухудшения и как можно было бы улучшить качество поиска по этим запросам, не ухудшая остальные запросы?
