# ЛР7. Булев индекс

Требования: Linux с glibc 2.35+, `g++` с C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Токенизатор — заголовок `../lab3/src/tokenizer.h`. Корпус — ЛР1, по умолчанию на 1 млн документов: тексты `../lab1/data_1m/text`, заголовки и ссылки `../lab1/data_1m/raw/<источник>/meta.jsonl` (источники находятся сами).

Запуск всего с нуля: `./run.sh [raw_dir text_dir]` — сборка, автотесты, список документов, индекс и замеры, отчёт (на 1 млн документов — около 20 минут: индекс строится 3 раза целиком и по частям).

- `scripts/doclist.py RAW TEXT > data/docs.tsv` — список документов: путь, заголовок, URL через табуляцию; номер строки — docID.
- `build/indexer [-s] [-c] INDEX < docs.tsv` — индексатор (C++ без STL, кроме токенизатора), печатает статистику и время; `-s` — индексировать основы слов (стеммер Портера из ЛР4, `../lab4/src/porter.h`), в заголовке ставится флаг 1; `-c` — сжать списки документов кодом Variable Byte (ЛР11, `../lab11/src/vbyte.h`), флаг 2.
- `src/index_reader.h` — чтение индекса (загрузка, двоичный поиск терма, `read_list` — список документов, при флаге 2 распаковывается); общий для `lookup` и поиска ЛР8.
- `build/lookup INDEX < words` — df и номера документов для каждого слова; `build/lookup INDEX -d < ids` — заголовок, URL и число токенов документа.
- `src/index_builder.h` — построение индекса (словарь, сортировка, запись файла); `src/indexer.cpp` — утилита поверх него.
- `tests/test_index.cpp` — юнит-тесты на C++, в них отдельный читатель формата по его описанию: `make test`, журнал — `results/tests.log`.
- `scripts/stats.py` — индекс `data/index.bin` (1,6 ГиБ), статистика (`results/stats.tsv`), индексация частей корпуса (`results/scale.tsv`), таблицы для отчёта.
- `report/` — отчёт (LaTeX) с побайтовым описанием формата, `report/report.pdf`.
