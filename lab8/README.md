# ЛР8. Булев поиск

Требования: Linux с glibc 2.35+, `g++` с C++17, `make`, Python 3.8+ (только стандартная библиотека), `pdflatex` для отчёта. Используются токенизатор ЛР3 (`../lab3/src/tokenizer.h`), стеммер ЛР4 и кодек ЛР11 (`../lab4/src/porter.h`, `../lab11/src/vbyte.h`) и индекс ЛР7 (`../lab7`: индексатор, `src/index_reader.h`, `data/index.bin`).

Запуск всего с нуля: `./run.sh` — сборка ЛР7 и поиска, индекс (если его ещё нет — 3–5 минут на 1 млн документов), автотесты, замеры, отчёт (около 2 минут).

- `build/search INDEX [-n LIMIT] [-o OFFSET] [-r REPEAT] < queries` — утилита командной строки: запрос на каждой строке, выдача — блоки `query/parsed/found/time_us` и строки `ранг, docID, заголовок, URL`, блок кончается пустой строкой. `-n 0` — все результаты, `-r` — повторить каждый запрос для замера времени.
- `build/search INDEX -p` — режим для веб-сервиса: строки `смещение<TAB>лимит<TAB>запрос`.
- `python3 web/server.py [--port 8080]` — веб-сервис: http://127.0.0.1:8080/ — форма, выдача по 50 результатов со ссылкой на следующие 50.
- Если индекс построен со стеммингом (флаг 1 в заголовке, ЛР4), слова запроса тоже приводятся к основам.
- Индекс со сжатыми списками документов (флаг 2, ЛР11, `indexer -c`) читается так же: список терма распаковывается при чтении.
- Синтаксис: пробел, `&&` или `&` — И; `||` или `|` — ИЛИ; `!` — НЕ; скобки. Например: `(castle || palace) germany !museum`.
- `src/query.h` — разбор и выполнение запросов; `src/search.cpp` — утилита поверх него.
- `tests/test_search.cpp` — юнит-тесты на C++: `make test`, журнал — `results/tests.log`; `tests/test_web.py` — тест веб-сервиса (он на Python), журнал — `results/tests-web.log`.
- `scripts/bench.py` — время запросов из `data/queries.txt` (`results/bench.tsv`, `bench-summary.tsv`), дамп выдачи (`results/examples.txt`), проверки согласованности на индексе корпуса (`results/consistency.txt`).
- `scripts/screenshot.py [INDEX [QUERY [PNG]]]` — скриншот выдачи для отчёта (нужен Firefox; в `run.sh` не входит).
- Если у индекса флаг 4 (частоты, ЛР13, `indexer -t`), выдача ранжируется по TF-IDF: запрос из одних слов — нечёткий, с операторами — булев с порядком по TF-IDF; пятый столбец — оценка (`../lab13/src/rank.h`).
- `report/` — отчёт (LaTeX), `report/report.pdf`.
